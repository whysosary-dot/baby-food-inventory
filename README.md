# 🍼 이유식 식재료 재고

아기 이유식 식재료의 **구매일자 / 재고량**을 관리하는 초경량 웹앱입니다.
아이폰·아이패드·맥에서 같은 데이터를 GitHub로 동기화해서 볼 수 있습니다.

**👉 https://whysosary-dot.github.io/baby-food-inventory/**

## 기능
- `+` / `−` 버튼으로 재고 조절 (기본 1회 = **5g**, 10g·30g 로 전환 가능)
- 숫자를 직접 눌러 정확한 값 입력
- 구매일자 기록 및 경과일(D+n) 표시 — 5일 이상 지나면 빨간색
- **날짜 / 재료명 / 재고량** 기준 정렬 (헤더나 칩을 다시 누르면 오름↔내림)
- 재료명 검색
- **커밋 & 푸시** 버튼으로 `data.json`을 GitHub에 저장 → 다른 기기에서 즉시 반영
- 앱으로 돌아올 때 자동으로 최신 데이터 불러오기
- 홈 화면에 추가하면 앱처럼 전체화면 실행 (PWA)

## 처음 설정 (기기마다 1회)
1. 사이트 접속 → 오른쪽 위 ⚙️
2. GitHub 토큰 붙여넣기 (권한: `repo`, 또는 이 저장소의 `Contents: Read and write`)
3. 저장

토큰은 **해당 기기 브라우저에만** 저장되며 저장소에 커밋되지 않습니다.

## 아이폰/아이패드 홈 화면 추가
Safari에서 사이트 열기 → 공유 버튼 → **홈 화면에 추가**

## 데이터
모든 데이터는 저장소의 [`data.json`](./data.json) 한 파일에 들어 있고,
수정할 때마다 커밋이 남으므로 변경 이력을 그대로 되돌아볼 수 있습니다.
